候选包含31份编排变化、16份任务要求修正、27份混合变化及6份仅澄清；151是文档数量，不是151种不同拓扑。80份静态复核记录为57份通过、23份附条件通过；静态结果不证明最优或实际执行正确。

必须先阅读执行前限定：两题的真正全天要求受固定日历工具能力限制；三份按该条意见范围保留其他原版问题；金融workshop题沿用原始题面，已知答案提示尚未统一清理。正式实验如更换题面或工具，应为同题所有候选及SA统一版本并重算哈希。

每份完整文档位于oracle_original/oracle_qixin/oracle_lexing/oracle_weiyi。metadata记录意见原文、修改引文、解释和限制；reviews是独立AI静态复核。原始个人标注数据库、隐藏GT预览、私有工作区路径和实验凭据不在本目录。

只向执行模型提供选中的一份Oracle和统一任务环境，不暴露其他候选或审阅材料。领域角色名称描述职责；接入公开Oracle preset时须统一映射到实际可调用的explore/coder等类型。run_matrix每行是一份尚未执行的候选，模型和重复编号留空；本目录未新增运行launcher。

完整生成包此前在服务器通过2989项完整性及溯源校验，报告见validation_report.json。本次Git分发保留候选、逐题说明与复核记录，不包含依赖完整私人标注快照的组装脚本；文件SHA256可用candidate_manifest.json逐一核对。

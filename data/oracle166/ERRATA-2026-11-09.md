## Version boundaries

- `data/oracle166/` contains the corrected execution guides. New Oracle-mode executions should identify this revision.
- The 26 original files from commit `4c1bbd3dc0d736623bba563e56cfd8666f85daac` are retained in [the source archive](../oracle166_history/README.md). Unchanged tasks keep their original source paths.
- Existing golden tags, cache entries, delegation categories, published scores and model results are historical artifacts. Only the affected golden records' source **paths** change; their original source hashes, LLM inputs, labels, cache keys and derived counts are preserved.
- The offline exporter replays each record's pinned source by default. An explicit mismatching `--oracle` is still rejected. A hash edit is not a new LLM review.
- These corrected guides have **not** been relabeled or benchmarked. Do not present the existing `F1_hit`/MSQ values as measurements of these new guides. Evaluation of the corrected revision requires separately versioned reviewed labels and execution traces.

This separation keeps historical results reproducible while making corrected instructions available. The [machine-readable manifest](../oracle166_history/2026-11-09.json) binds every old/new file to its SHA-256 and records the original cache keys.
